# dsh-plugin-admin

dsh（DeepSeek Harness）Web UI 管理插件：在官方设置界面内补齐 dsh 缺失的管理能力，共**十一个管理面板**（3 个独立设置页：Web 与会话 27 / 用量仪表盘 28 / 自动化 29；6 个页签：扩展插件在「插件」页内，技能、MCP 服务器、子智能体、命令、钩子 在「内置插件」页内；1 个输入框上方浮层：待办清单。第 11 个面板是「自动化」页内的第三个页签——定时任务 / Webhook / 工作流一页三页签）。零 dsh 导入，全部骑运行时 Cordis Context；缺服务逐面板降级，绝不整插件不加载。

面板文案内置简体/English 双语，接在 dsh 自己的语言服务上（`ctx.locale`）：工具栏 🌐 切换整个界面的语言，面板即时重绘、无需刷新。

**npm:** [`dsh-plugin-admin`](https://www.npmjs.com/package/dsh-plugin-admin) · v1.27.14 · MIT · 支持 dsh **≥ 0.1.7-rc.2**（验证基线 **0.2.0-rc.1**，见 [docs/COMPAT.md](docs/COMPAT.md)）
**🇬🇧 English documentation:** [README.en.md](./README.en.md)

## 十一个管理面板

| 面板 | 位置 | 能干什么 |
|---|---|---|
| 🔌 扩展插件 | 设置 → 插件 | 安装 / 卸载 / 更新 / 启停 profile 插件（pnpm 编排 + peer 兼容预检） |
| 📚 技能 | 设置 → 内置插件 | 全量技能清单（全局 + 各预设 + 会话作用域合并），严格只读 |
| 🔌 MCP 服务器 | 设置 → 内置插件 | 行级 CRUD + 真实握手探测 + 工具试调用台；改已挂载条目**热生效无需重启** |
| 🛰️ 子智能体 | 设置 → 内置插件 | 受管子代理 CRUD + 运行中监控/续接 + CLI 后端挂载 |
| ⌨️ 命令 | 设置 → 内置插件 | 提示词命令 CRUD / 导入导出，保存即实时生效 |
| 🪝 钩子 | 设置 → 内置插件 | hooks.json 编辑 + Claude / Codex 双桥一键安装，保存即热重启桥 |
| 🤖 自动化 | 设置 → 自动化 | 定时任务 + Webhook + 工作流一页三页签，各带模板卡片 |
| 🕘 历史会话 | 设置 → Web 与会话 | 搜索 / 置顶 / 目录折叠 / 批量删除 / 导出 Markdown / 体检 / 全文搜索 |
| 🔍 Web 搜索 | 设置 → Web 与会话 | provider 切换（Exa / Perplexity 等无官方 UI 的配置编辑），密钥只写不回显 |
| 📊 用量仪表盘 | 设置 → 用量仪表盘 | token 用量 / 活跃度分析；删会话不丢用量（台账三层兜底） |
| ✅ 待办清单 | 输入框上方浮层 | 实时待办 + git 文件变更区，无需打开设置 |

改动 profile 配置的操作（插件装卸/启停、MCP 新增/删除、Web 搜索、Webhook 运行时、overlay）**需重启 dsh 生效**，面板内会提示；MCP 已挂载条目的编辑是例外（热应用）。

## 安装

```sh
pnpm dsh plugin --profile web add dsh-plugin-admin   # 或本地路径 ~/dsh-plugin-admin
pnpm dsh --profile web                                # 重启 dsh 生效
```

## 常见任务

| 我想… | 去哪 | 要点 |
|---|---|---|
| 装一个扩展插件 | 设置 → 插件 → 扩展插件 | 顶部输入框填 npm 包名或本地绝对路径 → 回车 → 重启；自动做 dsh peer 兼容预检 |
| 批量清理历史会话 | 设置 → Web 与会话 → 历史会话 | 筛选后「🗑 删除当前 (N)」或目录头「🗑 整个目录」，先确认再执行；在线会话自动先关停；也可单会话「⬇ 导出」「🩺 体检」 |
| 加一个 MCP 服务器并试调用 | 设置 → 内置插件 → MCP服务器 | 表单保存 → 重启；「🔌 测试」真实握手，「🧪 试调用」真实 tools/call；**改已挂载条目保存即热生效，无需重启** |
| 建一个子智能体 | 设置 → 内置插件 → 子智能体 | 名称 / 提示词 / 工具约束 / 模型 / 后端；CLI 页签可挂 codex / claude-code / PATH 上的其他 agent CLI |
| 定时跑一个任务 | 设置 → 自动化 → 定时任务 | 模板卡片（工作日早报 / 周报 / 巡检）或结构化频率编辑器；动作 = steer 在线会话或新建会话；进程停机期间不补投 |
| 接一个 Webhook | 设置 → 自动化 → Webhook | 建规则拿 secret → `POST /webhook-triggers/<规则ID>` + 头 `x-webhook-secret`；默认仅本机投递；有交付历史与幂等去重 |
| 跑一个工作流（不会写代码也行） | 设置 → 自动化 → 工作流 | 「从模板开始」点卡片改参数即可启动；或会话里 `/workflow create <任务描述>` 让模型写脚本、干跑验证、后台启动 |
| 管理斜杠命令 / 钩子 | 设置 → 内置插件 → 命令 / 钩子 | 命令保存即注册，会话里 `/名称 <输入>`；钩子保存即热重启桥，未装桥先「⚡ 安装并挂载」 |
| 切换 Web 搜索 / 填 API key | 设置 → Web 与会话 → Web 搜索 | radio 选 provider → 重启；⚙ 编辑器保存 apiKey 等字段，密钥只写不回显 |
| 看 token 用量 | 设置 → 用量仪表盘 | 日期范围 + 项目筛选 + 趋势/热力图；删了会话用量也不丢 |
| 查有哪些技能 | 设置 → 内置插件 → 技能 | 只读清单，含模型/人类可调用旗标与作用域；📋 复制 `/name`、📂 打开目录 |
| 勾待办、看改了哪些文件 | 输入框上方浮层 | 随会话实时投影；git 变更区可 ⧉ 复制 diff、点击定位文件 |
